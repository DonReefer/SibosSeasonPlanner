# Sibos Season Planner

Sibos Season Planner is a season planning tool for **Pro Cycling Manager** (fan
project). Plan races and riders for a WorldTour team, check your season against
the in-game quality rules, and write the plan back into your career file.

**Download:** get the latest version under
[Releases](https://github.com/DonReefer/SibosSeasonPlanner/releases/latest).

**System requirements:** Windows (64-bit).

This is a **free fan project**. It is **not affiliated with Nacon / Cyanide**
(Pro Cycling Manager). **Beta** – please report anything that does not behave
as expected.
